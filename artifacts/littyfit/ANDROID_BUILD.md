# LittyFit — Android Build Guide (No EAS / No Cloud)

This is a fully native React Native Android project generated by `expo prebuild`.
Open it in Android Studio and build an APK or AAB the standard way.

---

## Prerequisites

- **Node.js** 18+ and **npm** or **pnpm** installed
- **Android Studio** (latest stable) with:
- Android SDK Platform 36
- Android SDK Build-Tools 36
  - NDK (Side by side) — Android Studio prompts to install this

---

## Step 1 — Install JS dependencies

Open a terminal in the `littyfit/` folder (the one that contains `package.json`):

```bash
npm install
# or
pnpm install
```

This must be done **before** opening Android Studio, because the Gradle build
scripts call `node` to resolve module paths from `node_modules`.

---

## Step 2 — Open in Android Studio

1. Open **Android Studio**
2. Choose **Open** (not "New Project")
3. Navigate to and select the **`littyfit/android`** folder
4. Click **OK** — Android Studio detects it as a Gradle project
5. Wait for **Gradle sync** to finish (first time takes 3–5 minutes; it downloads dependencies)

If Gradle sync fails with "SDK location not found":
- Go to **File → Project Structure → SDK Location**
- Set the Android SDK path (Android Studio may already have it)
- Or copy `local.properties.template` → `local.properties` and fill in your SDK path

---

## Step 3A — Build a debug APK (fastest, no signing needed)

**In Android Studio:**
- Menu: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
- Wait ~2–4 minutes for the first build
- Android Studio shows a popup: "APK(s) generated" with a **locate** link

**Or in terminal** (from the `android/` folder):
```bash
./gradlew assembleDebug
```

Output file:
```
littyfit/android/app/build/outputs/apk/debug/app-debug.apk
```

Install directly on a connected phone:
```bash
./gradlew installDebug
```

---

## Step 3B — Build a release APK (for distribution / Play Store)

### First: create your signing keystore (one time)

```bash
keytool -genkey -v \
  -keystore littyfit/android/app/littyfit-release.keystore \
  -alias littyfit \
  -keyalg RSA -keysize 2048 -validity 10000
```

### Then: create keystore.properties

Copy `android/keystore.properties.template` → `android/keystore.properties` and fill in:

```properties
storeFile=littyfit-release.keystore
storePassword=YOUR_STORE_PASSWORD
keyAlias=littyfit
keyPassword=YOUR_KEY_PASSWORD
```

### Build:

**In Android Studio:**
- Menu: **Build → Generate Signed Bundle / APK**
- Choose **APK** → **Next**
- Select your keystore file, fill passwords → **Next**
- Choose **release** build variant → **Finish**

**Or in terminal:**
```bash
./gradlew assembleRelease
```

Output file:
```
littyfit/android/app/build/outputs/apk/release/app-release.apk
```

---

## Step 3C — Build an AAB for Play Store

```bash
./gradlew bundleRelease
```

Output file:
```
littyfit/android/app/build/outputs/bundle/release/app-release.aab
```

Upload this `.aab` to Google Play Console under **Production → Create release**.

## Folder structure recap

```
littyfit/               ← JS source root (run npm install here)
  android/              ← Open THIS folder in Android Studio
    app/
      src/main/
        java/com/littyverse/littyfit/
          MainActivity.kt
          MainApplication.kt
        AndroidManifest.xml
        res/             ← icons, splash, colors
      build.gradle       ← app-level Gradle config
      debug.keystore     ← debug signing key (pre-included)
    build.gradle         ← root Gradle config
    settings.gradle
    gradlew              ← Gradle wrapper (use this to build from terminal)
```

## Troubleshooting

| Error | Fix |
|-------|-----|
| `SDK location not found` | Copy `local.properties.template` → `local.properties`, set sdk.dir |
| `node: command not found` | Install Node.js, make sure it's in your PATH |
| `node_modules not found` | Run `npm install` in the `littyfit/` folder first |
| Gradle sync timeout | Check internet connection; first sync downloads ~500MB of Android deps |
| Build fails on NDK | Android Studio → SDK Manager → NDK (Side by side) → install latest |
| `minSdkVersion` mismatch | Open `android/build.gradle`, check `minSdkVersion` matches your device |
