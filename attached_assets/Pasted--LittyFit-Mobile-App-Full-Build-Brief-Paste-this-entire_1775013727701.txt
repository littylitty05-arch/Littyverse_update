## What You Are Building

**LittyFit** is a standalone fitness and wellness mobile app for iOS and Android. It is the mobile companion to **Littyverse** — a full creative universe platform with its own cryptocurrency called **Littkoin (LTK)**. Users earn real LTK tokens by completing workouts, yoga sessions, and hitting hydration goals.

The app must be submission-ready for **Apple App Store** and **Google Play Store**.

The backend already exists and is fully deployed at:
EXPO_PUBLIC_API_URL=https://[FILL IN YOUR DEPLOYED LITTYVERSE URL]

Replace the URL above with your actual deployed Littyverse Replit app URL before building.

## Tech Stack

- Framework: Expo (React Native) with TypeScript
- Navigation: Expo Router (file-based) with bottom tabs
- State/Data: TanStack React Query (@tanstack/react-query)
- Auth Storage: expo-secure-store
- Haptics: expo-haptics (on button presses, completions, rewards)
- Icons: @expo/vector-icons (Ionicons)
- Animations: React Native's built-in Animated API + react-native-reanimated
- HTTP: Native fetch with a shared apiFetch() helper (see Auth section)

Install these packages first:
npx expo install expo-secure-store expo-haptics @tanstack/react-query react-native-reanimated

## Complete API Reference

Base URL: process.env.EXPO_PUBLIC_API_URL

### apiFetch helper — create this in lib/api.ts
import * as SecureStore from 'expo-secure-store';
const API_BASE = process.env.EXPO_PUBLIC_API_URL ?? '';
export async function apiFetch(path, options) {
  const token = await SecureStore.getItemAsync('ltk_token');
  return fetch(API_BASE + path, {
    ...options,
    headers: {
      'Content-Type': 'application/json',
      ...(token ? { Authorization: 'Bearer ' + token } : {}),
      ...(options?.headers ?? {}),
    },
  });
}

### Auth

POST /api/auth/mobile-login
Body: { identifier: "username_or_email", password: "string" }
Response 200: { token: "eyJ...", user: { id, username, email, firstName, profileImageUrl } }
Response 401: { message: "Invalid credentials" }
→ Store token with: SecureStore.setItemAsync('ltk_token', token)

GET /api/auth/mobile-me
Header: Authorization: Bearer <token>
Response 200: { id, username, email, firstName, profileImageUrl }
Response 401: token expired → show login

POST /api/auth/register
Body: { username, email, password, firstName }
Response 200: user object (follow up with mobile-login to get token)

### LittyFit Profile
GET  /api/littyfit/profile  → profile object or null (null = show onboarding)
POST /api/littyfit/profile
  Body: { goal, level, preference, interests[], dailyMinutes, currentProgramId, currentDay,
          calorieTarget, proteinTarget, hydrationTarget }

### Workouts
POST /api/littyfit/workouts/complete
  Body: { programId, dayIndex, durationSeconds, verified: boolean }
  Response: { ok: true, ltkEarned: 50 (verified) | 20 (honor) }

GET /api/littyfit/workouts/history
  Response: [{ id, programId, dayIndex, durationSeconds, ltkEarned, verified, createdAt }]

### Yoga
POST /api/littyfit/yoga/complete
  Body: { flowId, durationSeconds }
  Response: { ok: true, ltkEarned: 25 }

GET /api/littyfit/yoga/history
  Response: [{ id, flowId, durationSeconds, ltkEarned, createdAt }]

### Nutrition
GET  /api/littyfit/nutrition?date=YYYY-MM-DD
  Response: { date, calories, protein, carbs, fats, hydrationGlasses, hydrationGoalMet, ltkEarned } | null

POST /api/littyfit/nutrition
  Body: { date?, calories, protein, carbs, fats, hydrationGlasses }
  Response: { ...log, newLtkEarned: 10 if hydration goal just hit today }

### Progress
GET  /api/littyfit/progress
  Response: [{ date, weightLbs, energyLevel (1-5), mood (1-5), notes }]

POST /api/littyfit/progress
  Body: { date?, weightLbs?, energyLevel?, mood?, notes? }
  Response: { ok: true }

### Stats
GET /api/littyfit/stats
  Response: { totalWorkouts, totalYoga, totalLtk, streak, profile }

### LTK
GET /api/ltk/balance/:userId     → { balance: number, userId: string }
GET /api/ltk/history/:userId     → [{ actionType, points, description, createdAt }]

## Auth Flow

App launches
→ Read token from SecureStore
→ No token? Show LoginScreen
→ Token exists? GET /api/auth/mobile-me
  → 401 (expired)? Delete token → Show LoginScreen
  → 200 (valid)? GET /api/littyfit/profile
    → null? Show OnboardingScreen → POST /api/littyfit/profile → Home
    → exists? Show Home tab

## AuthContext — create this in context/AuthContext.tsx

import { createContext, useContext, useEffect, useState } from 'react';
import * as SecureStore from 'expo-secure-store';
import { apiFetch } from '../lib/api';

const AuthContext = createContext({ user: null, token: null, login: async () => {}, logout: async () => {}, isLoading: true });

export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);
  const [token, setToken] = useState(null);
  const [isLoading, setIsLoading] = useState(true);

  useEffect(() => {
    (async () => {
      const stored = await SecureStore.getItemAsync('ltk_token');
      if (stored) {
        const res = await apiFetch('/api/auth/mobile-me');
        if (res.ok) { setUser(await res.json()); setToken(stored); }
        else await SecureStore.deleteItemAsync('ltk_token');
      }
      setIsLoading(false);
    })();
  }, []);

  const login = async (identifier, password) => {
    const res = await apiFetch('/api/auth/mobile-login', {
      method: 'POST', body: JSON.stringify({ identifier, password }),
    });
    if (!res.ok) throw new Error((await res.json()).message);
    const { token: t, user: u } = await res.json();
    await SecureStore.setItemAsync('ltk_token', t);
    setToken(t); setUser(u);
  };

  const logout = async () => {
    await SecureStore.deleteItemAsync('ltk_token');
    setToken(null); setUser(null);
  };

  return <AuthContext.Provider value={{ user, token, login, logout, isLoading }}>{children}</AuthContext.Provider>;
}

export const useAuth = () => useContext(AuthContext);
